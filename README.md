# Оно тебе надо

Учебный проект Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/pravednovartem/ono-tebe-nado-ad

## Как открыть

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.
Изображения находятся в `images/`, шрифты — в `fonts/`, стили — в `styles/`.

## Страница

Страница содержит шапку с контактами, обложку, три карточки лотов, раздел об аукционе и подвал. Используются HTML, CSS и шрифт Raleway. Ширина страницы — 1100 px.

Ссылки меню ведут к разделам страницы. Карточки и ссылка «посмотреть больше» пока ведут к разделу лотов: отдельные страницы не входят в этот проект. Кнопка «Сделать ставку» — элемент учебного макета; отправка ставки не реализована.
